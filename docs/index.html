A short primer

How Enigma transforms a symbol

  1. The right rotor steps before every supported non-space symbol.
  2. The plugboard swaps the input before current enters the rotors.
  3. Current travels right-to-left through all three modulo-40 rotors.
  4. The reflector sends it back through the inverse wirings.
  5. The return signal passes through the plugboard again before a lamp illuminates.

When a rotor reaches its notch, it turns its neighbor. The middle rotor can move on two consecutive presses—the famous double-step.
